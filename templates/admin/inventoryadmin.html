{% if tab == 'audit' %} {# Reading a shelf, rather than scanning one. #}

Pick a board and read it against the list. Mark only what is not there or is out of place, then confirm the rest in one go. Borrowed copies are accounted for already. Anything still unfound is marked Missing — not lost, because books turn up. Giving up on one is a separate step on the Missing Stock tab.

Scanning a book on this board ticks it. Scanning one that belongs elsewhere says where it should go — which is the thing tapping down a list can never tell you.

Tap a row to mark it here. Tap the cross to mark it not found. Rows you never touch are covered by “the rest are here”, and the count records how many you confirmed one by one against how many were swept, so the shortcut shows in the history rather than hiding in it.
